# Visual models and Reels

## The layers of the tactic

- **Format/channel:** Reel, carousel, image, story, article.
- **Model:** the structure that organizes the reasoning (ladder, comparison, tree, list).
- **Template:** the composition you implement: proportions, hierarchy, areas and sequence.
- **Trend/reference:** a convention or example that helps execution. Popularity doesn't prove it works for your account.
- **Style:** language, identity, materials, rhythm and finish.

## Catalog of composition models

| Model | When to use |
|---|---|
| Evolution ladder | Progression or maturity with a clear criterion (not a list with no evolution) |
| Ecosystem map | Players, categories and the relationships between them |
| Grid of illustrated cards | Independent examples with image, name and description |
| Numbered execution sheet | Input, steps and output of an activity |
| Visual catalog | Options with icon, name and use |
| Anatomy: parts and functions | What makes up and supports a whole |
| Reference board by groups | Blocks to consult later, with hierarchy |
| Illustrated table | Categories with comparable attributes |
| Hierarchy in groups | Categories and subcategories |
| Scale zoom | From the whole to the detail, keeping the link |
| Architecture tree | Components, layers and connections |
| Decision tree | Paths and alternatives |
| Two-column comparison | Same criteria for equivalent alternatives |
| Scene with overlaid information | Labels anchored in a recognizable environment |
| Illustrated numbered list | A sequence of examples with an ordering criterion |
| Tiered ranking | Bands with an explicit criterion |
| Illustrated news | Fact, context and what changes for the audience |

How to choose: start from the piece's goal (attention, understanding, desire or action), identify the structure that best communicates the message (comparison, list, evolution, demonstration, story) and only then choose the model. Don't draw models at random to "vary". With three or more posts a day, don't repeat a model on the same day.

## Reels direction

Six decisions before producing: **concrete audience, goal, promise, visual proof, reveal and final action.**

Dominant language:
- **Motion:** typography, shapes, diagrams and data reveal an idea. Movement has to add information, not just decorate.
- **Animation:** characters or objects perform an action that causes a consequence and a transformation.
- **Cinematic:** a recognizable situation, observable action, cinematography and sound. Each shot has one central action. Use sparingly: it costs more and doesn't always reach more people.
- **Real demonstration:** screen recording or real use, supported by motion. An invented screen is not a demonstration.

Propose three truly different concepts (in the action and the reveal, not just the palette). Shot-by-shot script: time, new information, action, framing, exact on-screen text, sound and link to the next shot. The length serves the message.

## Video review

Watch it whole, with and without sound, at phone size. Check the opening, comprehension, progression, reveal, text readability, audio, correct data and the cover. Point out the three most serious problems with the exact time of each. A script doesn't prove rhythm or retention: without watching, the review stays pending.

The cover works on its own. The caption goes deeper, doesn't transcribe the video, and closes with an action.
