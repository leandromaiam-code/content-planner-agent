# content-planner-agent — a Claude Code skill

Makes Claude Code plan your content in the right order: audience, goal, strategy, topic, headline and only then the post. You get a calendar as a table, headlines scored against ten criteria and shot-by-shot Reels scripts. Works in English and Portuguese.

It plans. It does not generate media, schedule or publish anything.

## How to use

1. Download this repository (green **Code** button → **Download ZIP**), unzip it, and copy the `content-planner-agent` folder (with `SKILL.md` and the `references` folder) to:
   - `~/.claude/skills/` to use it in any project (on Windows: `C:\Users\<your user>\.claude\skills\`; create the folder if it doesn't exist); or
   - `.claude/skills/` inside your project folder, to use it only there.
2. Open Claude Code.
3. Ask, for example: *"Plan next month's Instagram content for my pilates studio."*
   Or call it directly: `/content-planner-agent`.
4. Tell it who your audience is, what you sell and what you've already posted. At the end you'll have the direction for the round, the calendar, the headlines with scores and the requested pieces.

## Como usar (português)

1. Baixe este repositório (botão verde **Code** → **Download ZIP**), descompacte e copie a pasta `content-planner-agent` (com o `SKILL.md` e a pasta `references`) para:
   - `~/.claude/skills/` para usar em qualquer projeto (no Windows: `C:\Users\<seu usuário>\.claude\skills\`; crie a pasta se não existir); ou
   - `.claude/skills/` dentro da pasta do seu projeto, para usar só nele.
2. Abra o Claude Code.
3. Peça, por exemplo: *"Planeja o conteúdo do Instagram do meu estúdio de pilates para o próximo mês."*
   Ou chame direto: `/content-planner-agent`.
4. Conte quem é o seu público, o que você vende e o que já postou. No final você terá a direção da rodada, o calendário, as headlines com nota e as peças pedidas, em português.
